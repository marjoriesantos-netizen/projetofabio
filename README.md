# Aura NFT Market

## 📌 Sobre o projeto

O **Aura NFT Market** é uma aplicação web desenvolvida para apresentar uma coleção de NFTs em uma interface moderna, responsiva e com tema escuro.

O projeto utiliza cards reutilizáveis para exibir informações das obras, como categoria, nome, descrição, criador e valor em ETH. A aplicação também possui navegação no cabeçalho, identidade visual própria e animações suaves de entrada.

##  Funcionalidades

* Exibição de uma coleção de NFTs.
* Cards reutilizáveis para apresentação dos itens.
* Renderização dos cards a partir de dados.
* Informações de categoria, nome, descrição, criador e preço.
* Cabeçalho responsivo com navegação.
* Tema visual escuro.
* Identidade visual e logotipo do projeto.
* Animações suaves de entrada.
* Layout responsivo para diferentes tamanhos de tela.
* Publicação da aplicação utilizando GitHub Pages.

##  Tecnologias utilizadas

* **HTML5** — estrutura da aplicação.
* **CSS3** — estilização, layout, responsividade e efeitos visuais.
* **JavaScript** — lógica da aplicação e renderização dos conteúdos.
* **Git e GitHub** — versionamento e hospedagem do código.
* **GitHub Pages** — publicação da aplicação na web.

##  Responsividade

A interface foi desenvolvida para se adaptar a diferentes tamanhos de tela, proporcionando uma boa experiência de navegação em computadores, tablets e dispositivos móveis.
